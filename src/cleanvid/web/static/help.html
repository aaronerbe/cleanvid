Overview

Cleanvid is an automated movie profanity filtering system designed for home media setups. It processes video files by analyzing subtitles to detect profanity and uses FFmpeg to create filtered versions with muted audio at those points.

Why Cleanvid? Some media players (like Roku devices) can't run real-time filtering plugins through Jellyfin/Plex. Cleanvid solves this by pre-processing videos so they're ready to play on any device.

How It Works:

  1. Finds or downloads subtitles for each video
  2. Scans subtitles for words in your profanity list
  3. Uses FFmpeg to mute audio during profanity timestamps
  4. Optionally applies scene filters (blur, black, skip)
  5. Copies the filtered SRT with profanity redacted
  6. Outputs clean video to your filtered media directory

Features

🔇 Audio Muting

Automatically mutes profanity detected in subtitles with configurable padding before/after each word.

🎬 Scene Filtering

Blur, black out, or completely skip scenes. Optionally mute audio during filtered scenes.

📥 Subtitle Download

Automatic subtitle download from OpenSubtitles when local subtitles aren't available.

📝 SRT Redaction

Copies subtitles to output with profanity replaced by underscores (e.g., "damn" → "____").

📁 Batch Processing

Process entire folders recursively or queue individual videos through the web interface.

🐳 Docker Ready

Runs in a Docker container with volume mounts. Perfect for NAS devices like Synology.

Web Dashboard

Main Dashboard

The main dashboard provides an overview of your system and quick access to all features.

System Status (Collapsible)

  • Container: Shows if Cleanvid is running
  • FFmpeg: Shows if FFmpeg is available
  • OpenSubtitles: Shows if subtitle downloading is enabled
  • Word List: Click to edit your profanity word list
  • Processing: Shows if a video is currently being processed

Processing Statistics (Collapsible)

  • Total Videos: Total videos found in input directory
  • Processed: Successfully processed videos
  • Unprocessed: Videos waiting to be processed
  • Failed: Click to view failed videos
  • % Complete: Overall progress

Actions

  • Browse & Process: Select specific videos or folders to process
  • Process All: Queue all unprocessed videos
  • Scene Editor: Define blur/black/skip zones for videos
  • View Queue: See processing queue and control jobs

Browse & Process

Navigate your video library and select what to process.

  • Click folders to navigate into them
  • Click the path breadcrumb to go back
  • Videos show their processing status (✓ processed, ⏳ pending, ✗ failed)
  • "Process This Folder" queues all videos in the current folder AND all subfolders
  • Click individual videos to queue them for processing

Scene Editor

Define custom scene zones for videos that need visual filtering.

Processing Modes:

  • Skip: Completely removes the scene from the video (output is shorter)
  • Blur: Applies Gaussian blur to the video during the time range
  • Black: Replaces video with black frames during the time range
  • Mute: Optional audio muting during blur/black scenes

How to Use:

  1. Select a video from the browser
  2. Enter start time (HH:MM:SS or MM:SS format)
  3. Enter end time
  4. Add a description (e.g., "Violence", "Nudity")
  5. Choose processing mode (Skip, Blur, or Black)
  6. Optionally enable "Mute audio" for blur/black modes
  7. Click "Add Zone" to save
  8. Add the video to the queue when done

⚠️ Note: Scene filters require video re-encoding, which takes longer than audio-only processing. Skip mode uses a two-pass process: first mutes profanity, then cuts the scenes.

Queue Management

Monitor and control the processing queue.

Queue Controls:

  • ⛔ Stop Now: Kills FFmpeg immediately and stops current job
  • ⏸️ Pause Queue: Lets current job finish, then pauses
  • ▶️ Resume Queue: Resumes processing after pause
  • 🔄 Force Reset: Clears stuck states and resets queue
  • 🗑️ Clear Pending: Removes all pending jobs from queue

Job Information:

Each job shows: video name, filter counts (blur/black/skip/profanity), processing step, and time elapsed.

Failed Videos

View and manage videos that failed processing.

Actions for Failed Videos:

  • Bypass: Copy video to output without filtering (marks as processed)
  • Reset: Clear failure status so video can be retried
  • Retry: Reset and immediately queue for reprocessing

Bulk Actions:

  • Bypass All: Bypass all failed videos
  • Reset All: Reset all failed videos
  • Retry All: Queue all failed videos for retry

CLI Commands

Cleanvid includes a full command-line interface. Access it via Docker:

docker exec -it cleanvid2 cleanvid [command]

Available Commands

cleanvid init

Initialize configuration files in the config directory.

cleanvid init [--config DIR]

cleanvid status

Show current system status including video counts and FFmpeg availability.

cleanvid status [--config DIR]

cleanvid process

Process videos in batch mode or a single video.

cleanvid process [VIDEO] [OPTIONS]

Options:
  VIDEO              Process specific video file
  --max-videos N     Maximum number of videos to process
  --max-time MINS    Maximum processing time in minutes
  --force            Reprocess already processed videos

Examples:

cleanvid process                           # Batch process
cleanvid process --max-time 300            # Process for 5 hours
cleanvid process /input/movie.mkv          # Process single video
cleanvid process --force                   # Reprocess all

cleanvid history

Show processing history.

cleanvid history [--limit N]

Options:
  --limit N    Number of entries to show (default: 20)

cleanvid reset

Reset processing status for videos.

cleanvid reset [VIDEO] [OPTIONS]

Options:
  VIDEO              Reset specific video
  --filter failed    Reset all failed videos
  --filter all       Reset all processed videos

cleanvid config

Show or validate configuration.

cleanvid config [OPTIONS]

Options:
  --show        Show configuration summary
  --validate    Validate configuration files

cleanvid web

Start the web dashboard (default command in Docker).

cleanvid web [OPTIONS]

Options:
  --port PORT    Port to run web server (default: 8080)
  --host HOST    Host to bind to (default: 0.0.0.0)

Global Options

--config DIR    Configuration directory (default: /config)
--verbose, -v   Enable debug logging
--quiet, -q     Suppress console output
--version       Show version

Configuration

Configuration is stored in /config/settings.json.

settings.json

Setting Default Description
processing
max_daily_processing 5 Max videos per batch run
max_processing_time_minutes 300 Max batch processing time
video_extensions [".mkv", ".mp4", ...] File types to process
mute_padding_before_ms 500 Mute padding before word (ms)
mute_padding_after_ms 500 Mute padding after word (ms)
paths
input_dir /input Source video directory
output_dir /output Filtered video output
opensubtitles
enabled true Enable subtitle downloading
language "en" Subtitle language code
username/password null OpenSubtitles credentials
ffmpeg
threads 2 FFmpeg thread count
audio_codec "aac" Output audio codec
audio_bitrate "192k" Output audio bitrate
re_encode_video false Re-encode video (slower)
video_crf 23 Video quality (lower=better)

profanity_words.txt

One word per line. Supports wildcards:

# Comments start with #
damn
hell
sh*t        # Matches shoot, shut, etc.
f*ck        # Matches any f-word variant

Edit via the web dashboard by clicking the "Word List" stat card.

Deployment

Docker Compose (Recommended)

Create a docker-compose.yml file:

version: '3.8'

services:
  cleanvid2:
    build: .
    image: cleanvid:2.0
    container_name: cleanvid2
    
    volumes:
      # Mount your video directories
      - /volume1/Videos:/input:ro              # Read-only input
      - /volume1/Videos-Filtered:/output       # Writable output
      - /volume1/docker/cleanvid2/config:/config
      - /volume1/docker/cleanvid2/logs:/logs
    
    ports:
      - "8080:8080"                             # Web dashboard
    
    environment:
      - TZ=America/New_York                    # Your timezone
    
    command: web
    restart: unless-stopped
    
    # Optional resource limits
    deploy:
      resources:
        limits:
          cpus: '2.0'
          memory: 2G

Deployment Steps

  1. Clone or copy the Cleanvid repository to your server
  2. Create the config and logs directories
  3. Edit docker-compose.yml with your paths
  4. Build and start: docker-compose up -d --build
  5. Access dashboard at http://your-server:8080
  6. Edit the word list via the dashboard
  7. Start processing videos!

Troubleshooting

Video fails with "No subtitle file found"

  • Ensure the video has an SRT file with the same name, or
  • Enable OpenSubtitles in settings with valid credentials
  • Check that the subtitle language matches your setting

Processing is slow

  • Scene filters (blur/black/skip) require video re-encoding
  • Audio-only processing (just profanity) is much faster
  • Increase ffmpeg.threads if your CPU supports it

Queue stuck in "Processing" state

  • Use the "Force Reset" button on the Queue page
  • Or restart the container: docker restart cleanvid2

SRT not copied to output

  • Check logs for "Warning: Failed to copy/adjust SRT"
  • Ensure output directory is writable
  • SRT copying happens after video processing succeeds

OpenSubtitles rate limit

  • Free accounts: 20 downloads per 24 hours
  • Consider VIP account ($10/year) for unlimited
  • Pre-download subtitles and place alongside videos
